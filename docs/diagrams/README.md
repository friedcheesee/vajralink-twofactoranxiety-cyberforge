# Diagrams

Open either file at <https://app.diagrams.net>: **File → Open from → Device**, or drag the file onto the page.

| File | Pages |
|---|---|
| `vajralink-architecture.drawio` | System architecture: interfaces, SAST, DAST, correlation engine, optional AI, storage, outputs |
| `vajralink-workflows.drawio` | Three pages: SAST workflow, DAST workflow, correlation and decisions |

Solid arrows always run. Dashed boxes and arrows are optional: they need an OpenAI key or are opt-in.
To export a PNG or SVG for slides: **File → Export as**.
